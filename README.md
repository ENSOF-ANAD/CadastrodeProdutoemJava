## 📌 Conteúdos abordados

As atividades deste repositório têm como objetivo desenvolver os fundamentos da programação utilizando **Java**, com exercícios simples e progressivos.

Entre os conteúdos trabalhados estão:

* Criação de projetos Java
* Pacotes e classes
* Variáveis e constantes
* Tipos de dados
* Entrada de dados com `Scanner`
* Saída de dados com `System.out`
* Operadores aritméticos
* Operadores relacionais
* Estruturas condicionais

  * `if`
  * `else`
  * `else if`
* Introdução à criação de objetos
* Resolução de problemas utilizando lógica de programação

## ▶️ Executando os exercícios

1. Abra o **Eclipse IDE**.
2. Importe ou abra o projeto Java.
3. Localize a classe que possui o método `main`.
4. Clique com o botão direito sobre a classe.
5. Selecione **Run As → Java Application**.
6. Acompanhe a execução pelo **Console** do Eclipse.
